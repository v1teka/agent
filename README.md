# agent

Телеграм‑бот, который пишет первым. Первая роль — **mentor**: утром даёт одно небольшое задание на день,
вечером спрашивает, как прошло, по ходу дня сам решает, когда напомнить, и всё время запоминает факты о тебе.

## Как это устроено

```
roles/  (mentor, потом hustle, agent…)   ← персона + её ритм: какие проверки и когда
core.py                                   ← проактивное ядро: решает, что сказать, что запомнить, когда написать снова
storage.py (SQLite)                       ← память: переписка, факты о человеке, задания, запланированные проверки
schedule.py                               ← тихие часы, бюджет сообщений, когда промолчать
llm.py                                    ← модель за интерфейсом LLM.think(); сейчас Claude, можно подключить другую
bot.py                                    ← Telegram
```

Каждый ход модель возвращает структурированный ответ: текст сообщения (или пустую строку — промолчать),
новые факты о человеке, новое задание, изменения статуса заданий и свои собственные будущие проверки
(«через 2 часа спросить, начал ли»). Бот сам пишет:

- по расписанию роли (у mentor: утро и вечер, время в `.env`);
- в моменты, которые модель запланировала сама.

Чтобы не превратиться в спам: тихие часы, дневной лимит сообщений (`DAILY_MESSAGE_BUDGET`), никаких
дополнительных напоминаний, если ты не ответил на два последних, и пауза, пока вы и так переписываетесь.

## Команды

- `/start` — знакомство и первое задание сразу, без анкет
- `/me` — что бот о тебе помнит, по разделам; `/forget N` — забыть факт
- `/tasks` — последние задания
- `/pause`, `/resume` — выключить и включить сообщения первым
- `/id` — узнать свой Telegram id

## Запуск на VPS (рекомендуется)

Боту нужен сервер, который работает круглосуточно, иначе он не сможет писать первым.

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
2. Получи API‑ключ на [platform.claude.com](https://platform.claude.com/settings/keys).
3. Арендуй самый простой VPS с Ubuntu 24.04: 1 ядро и 1 ГБ памяти хватит. Сервер должен быть
   в стране, где работает API Claude (например, Германия или Финляндия).
4. Зайди на сервер по SSH (`ssh root@IP-сервера`) и выполни:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/v1teka/agent/main/deploy/install.sh | sudo bash
   ```

   Скрипт поставит Docker, скачает бота в `/opt/agent`, спросит токен и ключ (они сохраняются только
   на сервере, в `/opt/agent/.env`), проверит, что Telegram и Claude отвечают с этого сервера,
   и запустит бота. Он перезапускается сам после сбоев и перезагрузки сервера.
5. Напиши боту `/start`, а потом `/id`, и впиши свой id в `ADMIN_USER_IDS` в `/opt/agent/.env`
   (если не ввёл его при установке). Перезапусти: `cd /opt/agent && docker compose restart`.

Обновить бота до свежей версии: выполнить ту же команду установки ещё раз, настройки и память сохранятся.
Логи: `cd /opt/agent && docker compose logs -f`.

## Запуск у себя

Скопируй `.env.example` в `.env`, впиши `TELEGRAM_BOT_TOKEN` и `ANTHROPIC_API_KEY` и запусти:

```bash
docker compose up -d --build
# или без Docker, Python 3.11+
python -m venv .venv && source .venv/bin/activate && pip install -e . && python -m agent
```

Данные лежат в `data/agent.db`.

## Доступ и лимиты

По умолчанию бот открыт для всех (`ACCESS=public`), а чтобы кто-то не сжигал токены, у всех, кроме
админов, есть лимиты:

- не больше `USER_DAILY_BUDGET_USD` (по умолчанию $0.50) в день на человека и `GLOBAL_DAILY_BUDGET_USD`
  ($3) в день на всех вместе. Расход считается по токенам из каждого ответа Claude и ценам из `.env`;
- не больше 5 сообщений в минуту и 60 в день на человека, сообщения длиннее 2000 символов не отправляются в модель;
- заблокированный человек не получает ответов, и бот перестаёт писать ему первым.

Админу (`ADMIN_USER_IDS`) бот сообщает о каждом новом пользователе и о том, что кончился общий дневной
лимит. Команды админа:

- `/stats` — сколько каждый потратил сегодня, за 7 дней и всего, с id и @username;
- `/block ID`, `/unblock ID` — заблокировать и разблокировать.

`ACCESS=private` пускает только админов и тех, кто перечислен в `ALLOWED_USER_IDS`.

## Модель

По умолчанию `claude-opus-5-5` с `effort=medium`. На `low` дешевле, но модель чаще путается: даёт два задания или поправляет себя прямо в сообщении.
Модель и effort меняются в `.env` (`CLAUDE_MODEL`, `CLAUDE_EFFORT`). Если фильтр безопасности отклонит запрос,
API сам повторит его на рекомендованной запасной модели.
